# Prisma Consultoria · Matriz SWOT

Aplicação web de página única que padroniza a aplicação da Matriz SWOT em uma
consultoria de administração.

## Contexto
Consultores usavam planilhas, Word e blocos de notas próprios, o que gerava
relatórios inconsistentes, retrabalho e falta de visão unificada dos projetos.

## Objetivo
Automatizar e padronizar o diagnóstico estratégico (SWOT) e o acompanhamento
dos planos de ação.

## Funcionalidades
- Matriz SWOT por cliente (Forças, Fraquezas, Oportunidades, Ameaças)
- Plano de ação: ação, responsável, prazo, método e custos
- Painel com % de conclusão e orçamento previsto vs. executado
- Relatório executivo padronizado, com exportação via impressão/PDF
- Interface responsiva, com tema claro e escuro

## Tecnologias
HTML, CSS e JavaScript (sem frameworks). Persistência via `localStorage`.

## Como executar
1. Clone o repositório ou baixe `swot-consultoria.html`
2. Abra o arquivo no navegador

## Estrutura
- `swot-consultoria.html`: aplicação completa

## Limitações e próximos passos
- Dados salvos apenas no navegador de cada usuário
- Futuro: back-end com banco de dados, login e painel consolidado para a diretoria
